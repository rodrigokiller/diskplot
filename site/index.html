The map and the list, in one window.

SpaceSniffer gave us the map. WizTree gave us the sortable tree. Diskplot keeps both on screen and ties them together: point at a block and its row lights up, pick a row and its block is outlined on the plan.

Four things beyond the map.

What grew since last time

Every scan leaves a small snapshot. Scan the same place again next month and the Changes tab lists the folders that gained weight, the new ones, and what disappeared. Growth is marked in red on the plan.

Developer clutter, totalled

node_modules, build output, package manager caches, virtual environments, temp folders and browser caches are recognised and added up, so you know how much comes back before you remove anything.

Find by name, size and age

Type part of a name and the matches appear as you type, largest first, across millions of files. Narrow by minimum size, by how long a file has gone untouched, or by type.

Duplicate files

Files of the same length are compared by content, a quick pass on the first and last bytes and a full hash only for the ones that still match. It runs when you ask for it, not during the scan.

Removing is a decision, so it asks.

Nothing leaves your disk without a confirmation, and what you remove goes to the Recycle Bin. Diskplot does not clean anything on its own and has no one-click fix.

Fast without asking for administrator rights.

Diskplot lists folders in bulk through the Windows directory API on every core, so no file is opened one by one. It also means the sizes you see are sizes on disk, not just file lengths.

How it sits next to the others.

WizTree

Reads the NTFS file table directly, which beats any tool that walks folders, Diskplot included. That needs administrator rights. It is closed source and asks for a paid licence at work.

SpaceSniffer

The treemap many of us learned this on, and the reason Diskplot uses one colour. Freeware and closed source, and it has no tree view.

WinDirStat

Open source like Diskplot, with a tree and a treemap coloured by file type. Diskplot adds scan comparison and clutter totals, and prints the map in one colour.

Questions people ask first.

Is it really free?

Yes. Diskplot is released under the MIT license. Use it at home and at work without paying, and read or change the source if you like.

Does it need administrator rights?

No. It scans everything your account can read. Folders it cannot open are counted and listed, so you know what is missing from the total. Run it as administrator if you want those included.

Why are the sizes different from File Explorer?

Diskplot reports the space a file occupies on disk. Compressed files, sparse files and OneDrive files that are online only take less room than their length suggests, and Diskplot counts what they really take. A file with several hard links is counted once per name.

Does it send anything about my files anywhere?

No. The only network request it makes is to GitHub, to see whether a newer version exists.

Is there a version for macOS or Linux?

Not yet. Windows 10 and 11 are the only supported systems today.
